## Descrição

Inicializar o projeto PULSO com Next.js 15 App Router, TypeScript strict, TailwindCSS com o design system da Land Grow, e shadcn/ui configurado com os componentes base necessários para todo o MVP.

---

## Contexto

O PULSO precisa de uma fundação moderna em Next.js 15 para suportar:

- Server Components (melhor performance, SEO)
- TypeScript strict (prevenir bugs críticos)
- Design system consistente (dark/light theme)
- shadcn/ui para componentes acessíveis (Radix)
- TanStack Table + Query (futuro Épico 1)

### Decisões técnicas

- **Next 16 ao invés de Next 15:** `create-next-app@latest` resolveu para 16.3.4 (Turbopack). Mantido — é compatível com React 19 e App Router.
- **React 19 + JSX global namespace:** adicionado `src/types/jsx.d.ts` para resolver `Cannot find namespace 'JSX'` em modo strict.
- **Supabase client lazy:** `createClient()` em `client.ts` e `server.ts` aceita modo dev com placeholder URLs (em `NODE_ENV !== 'development'` lança). Permite `npm run build` sem `.env` real.
- **ESLint ignore strategy:** flat config com `globalIgnores` para código vanilla JS legado (`views/`, `store.js`, `app.js`, etc.) e `aiox-core/`. Decisão Nayara: não tocar no BIN durante a migração.
- **theme-provider refatorado:** lazy `useState` initializer para ler `localStorage` (elimina warning `react-hooks/set-state-in-effect`), e `useEffect` separado para subscrever `prefers-color-scheme` apenas quando `theme === "system"`.
