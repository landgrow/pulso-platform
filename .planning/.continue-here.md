## Critical Anti-Patterns

| Pattern                                                         | Description                                                                                | Severity | Prevention Mechanism                                                                                   |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | -------- | ------------------------------------------------------------------------------------------------------ |
| Reusar cliente Supabase Auth no Drive                           | Cliente `PULSO - Supabase Auth` é login Google. Misturar redirect de Drive quebra o login. | blocking | Sempre usar o segundo cliente `PULSO Drive`. Nunca colar o ID do Drive no provider Google do Supabase. |
| Escopo `drive` inteiro                                          | Pede o Drive todo e trava verificação do Google.                                           | blocking | Só `drive.file` + `userinfo.email`.                                                                    |
| Commitar `.env.local` / aiox-core / fluent forms / graphify-out | Lixo e segredos.                                                                           | blocking | Commit só quando Nayara pedir. Nunca `.env*`.                                                          |
| Cron horário na Hobby                                           | `0 * * * *` derruba o deploy (`cron_jobs_limits_reached`).                                 | blocking | `vercel.json` já está `0 11 * * *` (8h Brasília). Não voltar para hourly.                              |
| Server Action síncrona                                          | `integrationLabels()` quebrou o build (`007bf5a`).                                         | advisory | Exports em `src/app/actions/*.ts` têm que ser `async`.                                                 |
