TaskModal appears and vanishes in 0ms

Whatif (!open) return null unmounts the kanban/WorkSmart overlay with no opacity or translate. Applied now: 180ms enter (opacity + 8px Y + 4px blur), 140ms subtler exit.

Why it mattersThis is the primary overlay. Instant hide reads as a crash; the user’s spatial model of “card still on the board” breaks.

Recommended motionKeep mounted for the exit. Enter 180ms cubic-bezier(0.22, 1, 0.36, 1). Exit 140ms, −8px, blur 2px. Overlay fades with it. Reduced-motion already global.

Sidebar animates width

Whattransition-[width] duration-200 on the rail. Width is a layout property — it reflows main content every frame.

Why it mattersCollapse is occasional, so 200ms is acceptable as a duration, but the property is the miss. Transform (or grid-template) would not thrash the HQ charts.

Recommended motionCollapse with transform: translateX on an absolutely padded rail, or CSS grid 224px → 56px without transitioning the chart column.
